# 場景二：供應鏈風險管理與替代料評估
## GPU Module 斷供危機應對方案

---

## 場景背景（開場白）

> 各位學員，現在進入場景二。英業達的關鍵零組件——GPU Module（由韓國 NovaTech 獨家供應）面臨多重風險：NovaTech Q3 產能預訂率已達 85%、交期從 8 週延長到 10 週、美中關稅變化可能影響中國備選方案。
>
> SCM 主管 Lisa Wang 需要快速完成三件事：
> 1. 評估替代供應商並產出比較表
> 2. 分析 BOM 成本影響
> 3. 向管理層提出建議方案（報告+簡報）
>
> 同時，她還要跟供應商溝通洽談、回覆內部各部門的問題。這個場景展示 Copilot 如何幫助 SCM 在時間壓力下快速產出高品質的分析交付物。

**涉及角色**：SCM（主導）、PM（專案影響評估）、BPM（流程調整）、IT（ERP 資料）
**使用的範例檔案**：
- 英業達_供應商評估表.xlsx
- 英業達_BOM成本分析.xlsx
- 英業達_供應商往來郵件串.docx
- 英業達_供應鏈風險分析報告.docx
- 英業達_供應鏈風險會議逐字稿.docx
- 英業達_PO採購訂單追蹤.xlsx
- 英業達_會議總結範本.docx

## Demo SCM-Teams：供應鏈風險會議的完整生命週期（會前→會中→會後）
**交付物**：會前議程 + 會中 Facilitator 筆記 + 會後多角度摘要 + 正式會議紀錄
**預計時間**：35-45 分鐘
**對應模組**：模組 5（管理會議與協作）
**範例資料**：**英業達_供應鏈風險會議逐字稿.docx**（7 人、56 分鐘完整逐字稿，含副總決策）

### ── 會前準備（10 分鐘）──

#### 步驟 1：用 Copilot Chat 準備會議（5 分鐘）

1. 開啟 Copilot Chat（Work 模式）
2. 輸入以下提示：
   ```
   我今天早上 10 點要主持一場「GPU 供應鏈風險評估暨替代方案討論會議」。
   與會者包含：James Chen (PM)、Kevin Liu (R&D)、Amy Hsu (QA)、Tom Lin (IT)、Sarah Chang (BPM)、Robert Tsai (製造副總)。

   請幫我準備：

   1. 會前簡報素材：
      - 搜尋 /英業達_供應商評估表.xlsx 中 GPU 三家供應商的關鍵比較數據
      - 搜尋 /英業達_PO採購訂單追蹤.xlsx 中 NovaTech 的在途 PO 和安全庫存狀況
      - 搜尋 /英業達_BOM成本分析.xlsx 中四個替代方案的成本比較

   2. 議程建議（含時間分配和每個議題的關鍵提問）

   3. 每位與會者應該準備什麼（我要在會前 1 小時發給他們）

   4. 副總 Robert Tsai 最關心的問題預測（他通常問：成本影響多少？風險有多高？什麼時候能搞定？）

   用條列格式，幫我在 10 分鐘內掌握全貌。
   ```
3. 展示 Copilot 從三份 Excel 中跨檔案彙整的結果

> 💡 **教學 Tip**：會前準備的關鍵是「預判副總會問什麼」。Copilot 不知道 Robert Tsai 是誰，但你在 prompt 中告訴它「他通常問什麼」，它就能幫你準備針對性的回答。

#### 步驟 2：用 Outlook Copilot 發會前通知（3 分鐘）

1. 在 Outlook 中新增郵件，使用 Copilot：
   ```
   草擬一封會前通知郵件給以下與會者：
   James Chen, Kevin Liu, Amy Hsu, Tom Lin, Sarah Chang, Robert Tsai

   主旨：【今日 10:00】GPU 供應鏈風險評估會議 — 請準備以下資料

   內容：
   1. 會議目的：評估 GPU Module 供應風險，決定供應商策略
   2. 議程概覽（7 個議題，共 90 分鐘）
   3. 請各位準備：
      - Kevin：SE-Pro 與 NT-500 的技術相容性初步評估
      - Amy：導入第二供應商需要的品質驗證清單
      - Tom：ERP 和 MES 系統變更的影響評估
      - Sarah：供應商導入流程的時程估算
      - James：如果切換供應商，對 ProServer X200 時程的影響
   4. 參考資料：供應商評估表和 BOM 成本分析已放在 SharePoint

   語氣正式但友善，強調這是緊急議題。
   ```
2. 展示 Copilot 的草稿，直接發送

#### 步驟 3：用 PPT Copilot 快速做會前簡報（2 分鐘）

1. 在 PowerPoint 中使用 Copilot：
   ```
   建立一份 5 頁的會議引導簡報：
   1. 封面：GPU 供應鏈風險評估 — 2025/4/18
   2. 現況：NovaTech 100% 供應，Q3 產能 85%，交期 8→10 週
   3. 三家供應商比較摘要（根據 /英業達_供應商評估表.xlsx）
   4. 四個替代方案的成本比較（根據 /英業達_BOM成本分析.xlsx）
   5. 今天需要做的決定：選擇哪個方案？核准驗證預算？
   ```

> 🎯 **會前 Takeaway**：所有資料都從預建的 Excel 檔案自動擷取，不需要手動整理。

### ── 會中協作（10 分鐘）──

#### 步驟 4：啟用 Facilitator（3 分鐘）

1. 加入 Teams 會議
2. 開啟 **Notes** 面板
3. 在會議聊天中輸入：
   ```
   @Facilitator 今天的供應鏈風險評估會議議程如下：
   1. 供應現況與風險概述 (15 min)
   2. 替代供應商評估結果 (20 min)
   3. 技術相容性評估 (10 min)
   4. 品質驗證需求 (10 min)
   5. BOM 成本影響分析 (15 min)
   6. IT 系統變更影響 (5 min)
   7. 決議與行動計畫 (15 min)

   會議 90 分鐘，請在 45 分鐘時提醒。
   ```
4. Facilitator 開始追蹤議程進度

#### 步驟 5：會中使用 Facilitator 五大操作（5 分鐘）

模擬會議進行（可參考 **英業達_供應鏈風險會議逐字稿.docx** 中的對話內容口述）：

**操作 1 — 記錄副總決議**
```
@Facilitator 決議：Robert 副總核准啟動雙供應商策略（NovaTech 60% + SiliconEdge 40%），
並核准驗證費用 USD 45,000。
```

**操作 2 — 標記行動項目**
```
@Facilitator 行動項目：
- Lisa Wang 在 4/25 前啟動 SiliconEdge 供應商導入
- Kevin Liu 在 4/25 前完成技術相容性評估報告
- Amy Hsu 在 4/30 前完成品質驗證計畫書
```

**操作 3 — 記錄風險項目**
```
@Facilitator 風險紀錄：NovaTech 如果得知我們有第二供應商，可能影響合作關係。
Lisa 的緩解策略是將 dual source 定位為「分散供應風險」而非「不滿意」。
```

**操作 4 — 半程提醒**
→ Facilitator 在 45 分鐘時自動提醒：「會議已到半程，還有 3 個議程未討論。」

**操作 5 — Wrap-up 彙整**
```
@Facilitator 請整理今天的所有決議和行動項目，列出負責人和截止日期
```

#### 步驟 6：會中私下用 Copilot 查資料（2 分鐘）

同時在 Copilot 側邊面板（私密）：
```
Robert 副總問「停線一個月的營收損失是多少」。
請根據 /英業達_PO採購訂單追蹤.xlsx 的安全庫存狀況表，
計算 ProServer X100 如果 GPU 斷供，多少天後會停線？
月營收損失大約多少？（月產 2 萬台 × 售價 USD 8,000）
```

> 💡 **教學 Tip**：副總臨時問數字，你不用翻 Excel——Copilot 3 秒內從預建檔案中算出來，你只要看著回答就好。

### ── 會後產出（15-20 分鐘）──

#### 步驟 7：AI Summary 標準摘要（2 分鐘）

1. 會議結束後，在 Teams 行事曆中找到此會議
2. 點擊 **Recap** → 展示 AI Summary 的自動摘要
3. 說明這是「標準版」，接下來我們要產生不同角度的版本

#### 步驟 8：副總角度的 30 秒摘要（3 分鐘）

在 Copilot 側邊面板中輸入（或使用 **英業達_供應鏈風險會議逐字稿.docx** 貼入 Copilot Chat）：
```
請用「製造副總 Robert Tsai」的角度摘要這場供應鏈風險會議。
他剛才參加了會議，現在要跟 CEO 報告 30 秒。

格式：
🚦 決策結果：[一句話]
💰 財務影響：[一個數字]
⏰ 預計完成時間：[一個日期]
⚠️ 殘餘風險：[一句話]

不超過 5 行。
```

**範例產出**：
```
🚦 決策結果：核准雙供應商策略（NovaTech 60% + SiliconEdge 40%），驗證預算 USD 45K
💰 財務影響：年度 GPU 成本增加約 USD 1.2M，但避免單一供應商斷供風險（最大損失 USD 160M/月）
⏰ 預計完成時間：6 月初完成驗證，6 月中開始量產使用
⚠️ 殘餘風險：需妥善溝通 NovaTech 以維持合作關係
```

#### 步驟 9：SCM 主管的完整追蹤版（3 分鐘）

```
請用「供應鏈經理 Lisa Wang」的角度摘要這場會議。
Lisa 是會議主席，她需要追蹤所有行動項目的執行。

格式：
一、決議事項（含核准者和生效條件）
二、我的行動項目（Lisa 的 5 個待辦，含截止日）
三、我需要別人完成的事（誰 / 什麼 / 什麼時候給我）
四、需要跟進的風險
五、下次會議準備事項
```

依序產生三個角度：

✅ 我要做的事（含技術細節）：adapter bracket 規格、BIOS/BMC 更新需求

✅ 驗證項目清單（IQC 標準、burn-in、HALT/HASS、相容性、FAI）
📎 我需要的資源：SE-Pro sample 料到貨時間

⚠️ 注意事項：出貨記錄需標記 GPU 來源

## Demo 6：Outlook — 供應商溝通與 Coaching
**交付物**：供應商詢價郵件 + Follow-up 郵件
**預計時間**：15-20 分鐘
**對應模組**：模組 3（草擬商業內容）+ 模組 5

### 步驟 1：使用 Copilot 摘要郵件串（5 分鐘）

1. 開啟 Outlook。
   - **方式 A（推薦）**：事先用練習環境的帳號互寄 4 封郵件，內容從 **英業達_供應商往來郵件串.docx** 複製貼上，形成一串真實的 Outlook 郵件串
   - **方式 B（備案）**：直接開啟 **英業達_供應商往來郵件串.docx** 作為參考，在 Copilot Chat 中貼入郵件內容進行分析
2. 在郵件串頂部找到 **「Summary by Copilot」** 按鈕，點擊
3. Copilot 會自動產生郵件串摘要，包含：
   - 討論的主要議題
   - 每封郵件的關鍵資訊
   - 待處理事項
4. 展示摘要結果，說明這對 SCM 的價值：不需要逐封重讀郵件，幾秒鐘掌握完整脈絡

5. 進一步在 Copilot 面板提問：
   ```
   NovaTech 最終的報價條件是什麼？包含價格、交期、品質保證和付款條件
   ```
6. Copilot 會從郵件串中精準提取相關資訊

> 💡 **教學 Tip**：SCM 每天處理大量供應商郵件，郵件串常常 10-20 封。Copilot 的摘要功能可以在接手別人的供應商溝通時，幾秒鐘了解前因後果。

### 步驟 2：使用 Copilot 草擬供應商詢價郵件（5 分鐘）

1. 在 Outlook 中點擊 **New Mail**（新郵件）
2. 點擊 Copilot 的 **Draft with Copilot** 按鈕
3. 輸入以下提示：
   ```
   請幫我草擬一封郵件給 SiliconEdge 的業務代表 Mr. Takeshi Yamamoto (takeshi.yamamoto@siliconedge.co.jp)，內容包含：
   
   1. 自我介紹：我是英業達供應鏈管理部的 Lisa Wang
   2. 說明我們正在評估 GPU Module 供應商，對 SE-Pro 型號有興趣
   3. 詢問以下資訊：
      - 年用量 240K pcs 的最優惠價格
      - 標準交期及急單能力
      - 品質認證文件（ISO、可靠度報告）
      - 台灣的技術支援及 FAE 駐點
      - 是否接受 Net 60 付款條件
   4. 提到我們希望在 4 月底前收到正式報價
   5. 語氣專業、友善，展現長期合作誠意
   
   郵件使用英文撰寫。
   ```
4. 展示 Copilot 產生的草稿
5. 可以嘗試 **Regenerate**（重新產生）看不同版本的差異

> 💡 **教學 Tip**：提示越具體，結果越精準。注意我們在提示中明確指定了收件人、背景、要詢問的項目清單、語氣和語言——這就是「角色 + 任務 + 上下文 + 格式 + 語氣」的提示公式。

### 步驟 3：使用 Coaching 功能調整郵件（5 分鐘）

1. 草稿產生後，**不要直接發送**
2. 點擊 Copilot 的 **「Coaching by Copilot」** 按鈕
3. Copilot 會分析你的郵件並給出建議，例如：
   - 📌 **Tone（語氣）**：「Your email is professional. Consider adding a warmer opening.」
   - 📌 **Clarity（清晰度）**：「Consider numbering your questions for easier reference.」
   - 📌 **Sentiment（情感）**：「The email reads as slightly formal. This is appropriate for a first contact.」
4. 展示如何根據 Coaching 建議修改郵件
5. 示範不同語氣的調整：
   - 點擊 **Adjust tone** → 選擇 **Direct**（更直接）
   - 觀察郵件的措辭變化
   - 再選擇 **Formal**（更正式）
   - 觀察差異

6. 示範長度調整：
   - **Make it shorter**：適合後續日常溝通
   - **Make it longer**：適合首次正式接觸

> 💡 **教學 Tip**：Coaching 功能的價值不在於改錯字，而在於幫你用對「語氣」。跟日本供應商要用什麼語氣？跟中國供應商又不同。SCM 的郵件語氣直接影響談判氛圍。

### 步驟 4：草擬會議 Follow-up 郵件（3 分鐘）

## 加碼實戰情境：SCM 的一天（貼近日常的 Copilot 應用）

以下是英業達 SCM 在供應鏈管理中實際會遇到的高頻情境。每個情境都有完整的 Copilot 提示，可穿插在 Demo 之間或作為進階練習。

### 實戰情境 A：供應商緊急斷料通知

> **背景**：星期二早上 8 點，NovaTech 的 David Park 發了一封郵件：「Dear Lisa，因為我們的晶圓代工廠火災，NT-500 未來 6 週無法出貨。已經在途的這批不受影響，但之後的 PO 都會 delay。」
>
> **痛點**：你必須在 2 小時內完成影響範圍評估、啟動備援供應商、通知所有受影響的產品線 PM、跟管理層報告。

**步驟 1 — 用 Excel Copilot 快速評估影響範圍**

開啟 **英業達_PO採購訂單追蹤.xlsx**（Sheet: GPU Module PO追蹤），使用 Copilot：
```
請根據 /英業達_PO採購訂單追蹤.xlsx 中 GPU Module PO追蹤表的 NovaTech NT-500 採購訂單資料，分析：
1. 目前在途的 PO 有哪些？預計到貨日期？數量？
2. 接下來 6 週內預計要下的 PO 有哪些？影響的產品線？
3. 目前的安全庫存可以撐多少週？
4. 如果 6 週後才恢復供貨，產線什麼時候會斷料？

用紅黃綠標記每個產品線的緊急程度。
```

**步驟 2 — 用 Outlook Copilot 快速通知所有 PM**

```
請幫我草擬一封緊急通知郵件給以下 PM：
- James Chen (ProServer X200)
- Mike Wang (ProServer X100)
- Jenny Lee (CloudBook L15)

主旨：【緊急】NovaTech NT-500 GPU Module 斷料通知 — 影響評估

內容：
1. 事件描述：NovaTech 晶圓代工廠火災，NT-500 未來 6 週無法出貨
2. 影響範圍：[列出每個產品線的影響]
3. 目前安全庫存狀況
4. 我已經啟動的應對措施：
   - 聯繫 SiliconEdge 確認緊急供貨能力
   - 確認在途 PO 不受影響
   - 今天下午 3 點召開緊急會議
5. 需要 PM 在今天中午前回覆各自產品線的優先順序

語氣緊急但冷靜，展現 SCM 已經在處理。
```

**步驟 3 — 用 Copilot Chat 準備緊急會議簡報**

```
請幫我快速準備一份 3 頁的緊急簡報（PPT），用於今天下午 3 點的斷料應變會議：

第 1 頁：事件摘要
- NovaTech 晶圓代工廠火災
- 影響零件：NT-500 GPU Module
- 斷供期間：6 週

第 2 頁：影響評估
- 各產品線影響（表格：產品線/月用量/安全庫存/斷料日期）
- 營收風險金額

第 3 頁：應變方案
- 方案 A：SiliconEdge SE-Pro 緊急供貨（交期 6 週，單價 +$13）
- 方案 B：向 NovaTech 爭取其他工廠調貨
- 方案 C：調整產線排程，優先消化高毛利產品

格式簡潔，適合快速報告。
```

> 💡 **教學 Tip**：供應商斷料是 SCM 最怕的事。這個情境展示了 Copilot 在**危機處理**中的價值——不是幫你做決策，而是幫你在壓力下**更快、更完整地收集資訊和通知相關人員**。

### 實戰情境 B：進料品質異常處理

> **背景**：IQC (Incoming Quality Control) 在早班抽檢時發現，MemoryPlus 這批 DRAM 的不良率高達 8.5%（正常 <1%）。已有 200 條用到產線組裝了。
>
> **痛點**：你需要同時處理五件事：通知供應商、安排退貨、確認產線影響、更新安全庫存策略、寫異常處理報告。

**步驟 1 — 用 Outlook Copilot 發出供應商品質投訴函**

```
請草擬一封正式的品質投訴函 (Quality Complaint Letter) 給 MemoryPlus 的品質經理 Mr. Zhang Wei (zhangwei@memoryplus.cn)，內容：

1. 不良品描述：
   - 零件：MP-DDR5-32 (DDR5 32GB ECC RDIMM)
   - PO 編號：PO-2025-04-1082
   - 批號：LOT-20250410-A3
   - 到貨數量：5,000 pcs
   - 抽檢不良率：8.5%（AQL 0.65 標準下 Reject）
   - 不良現象：上電後出現 correctable ECC error，特定位元位置反覆出錯

2. 要求：
   - 48 小時內提供初步根因分析 (Preliminary FA Report)
   - 5 個工作天內提供 8D 報告
   - 立即安排替換品空運出貨（費用由 MemoryPlus 承擔）
   - 暫停同批號的後續出貨，全數重新檢驗

3. 已知影響：
   - 200 條已上線組裝，需要排查已組裝的機台
   - 預計影響 3 天的產線產出

語氣正式嚴肅但不失禮，引用合約中的品質條款。英文撰寫。
```

**步驟 2 — 用 Word Copilot 寫內部異常處理報告**

```
請撰寫一份內部品質異常處理報告 (Quality Non-Conformance Report)：

報告編號：QA-2025-058
零件/供應商：DDR5 32GB / MemoryPlus
異常發生日期：2025/4/14
異常發現方式：IQC 抽檢
異常描述：不良率 8.5%（正常 <1%），ECC error
影響範圍：5,000 pcs 到貨批次 + 200 pcs 已上線
產線影響：預估影響 380 台 ProServer X100 的組裝時程
財務影響：重工成本約 USD 12,000 + 產線停機損失約 USD 85,000

處置措施：
1. IQC：全批 Reject，隔離待退
2. 產線：已組裝 200 pcs 全數下線重驗
3. SCM：已通知供應商 48 小時內提供 FA 報告
4. 安全庫存：啟用 NovaTech 備援庫存 800 pcs 補充產線

後續追蹤：
- 預計 4/16 收到 MemoryPlus 的初步 FA
- 4/21 前完成 8D 報告審查
- 評估是否將 MemoryPlus 降級或暫停供貨資格

語氣專業，含具體數字。
```

> 💡 **教學 Tip**：品質異常是 SCM 和 QA 的共同戰場。這個情境展示了對外（供應商投訴函）和對內（異常處理報告）兩種不同文件的快速產出。注意語氣差異——對外要引用合約條款、對內要量化財務影響。

### 實戰情境 C：供應商議價談判準備

> **背景**：NovaTech 下個月合約到期，他們提出明年漲價 8%（從 $285 漲到 $308）。你需要準備議價策略，下週跟 NovaTech 的 VP Sales 開會。
>
> **痛點**：你需要市場行情分析、競爭報價比較、內部成本承受力計算、談判話術準備。

**步驟 1 — 用 Researcher Agent 搜集市場行情**

```
搜尋以下資訊，幫我準備與 NovaTech 的價格談判：
1. 2025 年 GPU Module 的全球市場均價趨勢
2. PCIe Gen5 GPU Module 的主要供應商和市場份額
3. 預估 2026 年 GPU Module 的價格走勢（漲或跌？）
4. 同級產品的競品報價區間

中文摘要，附來源連結。
```

**步驟 2 — 用 Excel Copilot 計算議價底線**

```
根據 /英業達_BOM成本分析.xlsx，分析以下情境：

1. 如果 GPU 漲價 8%（$285 → $308），每台 BOM 增加多少？年度總影響？
2. 我們的目標售價對 HP 的毛利率是多少？漲價後毛利率變化？
3. 我們最多能接受多少漲幅而不影響專案的最低毛利率要求（假設 12%）？
4. 如果用 SiliconEdge 替代（$298），跟 NovaTech 漲價後的 $308 比，哪個更划算？（含 TCO）

產出一個「議價區間分析表」：
- 理想價格：____
- 可接受價格：____
- 走人價格（觸發切換供應商）：____
```

**步驟 3 — 用 PPT Copilot 準備談判簡報**

```
建立一份 5 頁的議價談判簡報（內部使用，不給供應商看）：

1. 談判目標：控制漲幅在 3% 以內（目標價 $293-$294）
2. 我方籌碼：
   - 年用量 240K，是 NovaTech 前三大客戶
   - 已完成 SiliconEdge 驗證，隨時可切換
   - 12 個月長約鎖量的承諾
3. 對方可能論點及反駁：
   - 「原物料漲價」→ 我們查到市場均價只漲 3-4%
   - 「產能緊張」→ 我們有備援供應商
4. 讓步空間：最多接受 5%，但要求 Q3 產能保證
5. BATNA（最佳替代方案）：切換到雙供應商策略

每頁含講者備忘稿和建議的「話術」。
```

> 💡 **教學 Tip**：議價談判是 SCM 最核心的能力。Copilot 幫你做的是**數據支撐的談判準備**——議價底線計算、市場行情佐證、反駁話術。真正的談判還是靠人，但準備功課用 Copilot 做得更快更完整。

### 實戰情境 D：年度供應商績效回顧信

> **背景**：每年年底 SCM 都要發一封「年度供應商績效回顧信」給每個關鍵供應商，包含他們這一年的交期、品質、配合度評分，並提出明年的改善期望。
>
> **痛點**：你有 15 家供應商，每封信的數據不同、重點不同，但格式相同。

**用 Copilot 批次產生個人化的績效回顧信**

```
請根據 /英業達_供應商評估表.xlsx 中 NovaTech 的數據，草擬一封年度供應商績效回顧信。

格式：
1. 開頭感謝 2025 年的合作
2. 績效回顧：
   - 品質評分：4.2/5（好於平均但仍有改善空間）
   - 交期表現：標準 8 週，但 Q4 延長至 10 週（-25%）
   - 不良率：150 PPM（高於我方 <100 PPM 的目標）
   - 技術支援：回應 4 小時，滿意
3. 2025 年的亮點和感謝
4. 2026 年的期望：
   - 不良率降至 100 PPM 以下
   - 交期恢復並維持在 8 週
   - 季度績效回顧會議
5. 持續合作的承諾

語氣：正面為主，但清楚指出需要改善的地方。英文。

完成後，請同樣的格式，改用 ChipMax 的數據再產生一封。
```

> 💡 **教學 Tip**：15 家供應商 × 每封 30 分鐘 = 將近一天的工作。Copilot 可以幫你產生初稿，你只需要花 5 分鐘/封做個人化調整。這就是 Copilot 在「批量文件」場景中最大的時間節省。

### 實戰情境 E：跨時區供應商會議的事前準備

> **背景**：明天早上 7 點要跟日本 SiliconEdge 開第一次 Teams 會議（日方 8 點）。你需要準備會議簡介、要討論的議題、以及對方公司的背景調查。
>
> **痛點**：你只有下班前 1 小時可以準備，而且你對 SiliconEdge 不太熟。

**一站式準備**

```
我明天早上 7 點要跟日本供應商 SiliconEdge 開第一次 Teams 會議。
請幫我做以下準備：

1. 公司背景調查（用 Researcher Agent）：
   - SiliconEdge 的公司規模、主要產品、客戶群
   - 日本企業文化中開會的注意事項

2. 會議議程草案：
   - 相互介紹（10 min）
   - 英業達需求說明（10 min）
   - SE-Pro 技術規格討論（15 min）
   - 商務條件初步探討（15 min）
   - Next steps（5 min）

3. 問題清單（我要問他們的）：
   - 根據 /英業達_供應商評估表.xlsx 中 SiliconEdge 的數據，列出我需要確認的商務和技術問題

4. 會議邀請郵件（英文，發給 SiliconEdge 的 Takeshi Yamamoto）：
   - 確認時間、Teams 連結、議程
   - 語氣禮貌尊重（日本商業文化）

請一次幫我做完這四件事。
```

> 💡 **教學 Tip**：跟不同國家的供應商開會，文化敏感度很重要。跟日本供應商要更禮貌正式，跟韓國供應商可以稍微直接。Copilot 可以幫你調整語氣，但文化判斷還是要靠你。

### 練習 A：郵件草擬練習（10 分鐘）
