# Teams 會議全流程 Demo：會前 → 會中 → 會後
## AI 驅動的完整會議生命週期

---

## 教學目標

> 這個 Demo 展示 Copilot 如何介入會議的**完整生命週期**——不只是會後摘要，而是從會前準備到會中協作到會後多角度產出。讓學員理解：**一場會議的價值，80% 來自會前準備和會後行動，只有 20% 在會議本身。**

```
┌─────────────┐    ┌─────────────┐    ┌─────────────────────────┐
│  🔍 會前     │ →  │  🎯 會中     │ →  │  📝 會後                 │
│             │    │             │    │                         │
│ • 議程準備   │    │ • Facilitator│   │ • AI Summary            │
│ • 與會者研究 │    │   即時主持   │    │ • 客製化摘要（多角度）    │
│ • 前次會議   │    │ • 即時筆記   │    │   - CEO 角度             │
│   追蹤      │    │ • 即時 Q&A   │    │   - PM 角度              │
│ • 資料彙整   │    │ • 行動追蹤   │    │   - 一般員工角度          │
│ • 簡報準備   │    │ • 時間提醒   │    │   - 客戶報告角度          │
│             │    │             │    │ • Word 正式會議紀錄       │
│             │    │             │    │ • Follow-up 郵件          │
│             │    │             │    │ • 行動項目 → Planner      │
└─────────────┘    └─────────────┘    └─────────────────────────┘
```

**預計總時間**：45-60 分鐘（可拆成三段分別進行）
**使用的範例檔案**：
- 英業達_NPI_Kickoff_會議逐字稿.docx（模擬轉錄稿）
- 英業達_NPI_設計審查會議逐字稿.docx（模擬轉錄稿）
- 英業達_NPI_ProServerX200_專案追蹤.xlsx（專案資料）
- 英業達_會議總結範本.docx（多角度摘要範本）

# 第一段：會前準備（15 分鐘）

## Demo A：用 Copilot 準備會議——「今天下午的 Design Review 我該準備什麼？」

> **情境**：James Chen (PM) 今天下午 2 點有一場 ProServer X200 的第二次設計審查會議。他 1 點才從另一個客戶的電話中解脫出來，只剩 1 小時準備。

### 步驟 1：用 Copilot Chat 做會前 Catch-up（5 分鐘）

1. 開啟 Microsoft 365 Copilot Chat（Work 模式）
2. 輸入以下提示：
   ```
   我今天下午 2 點有一場 ProServer X200 設計審查會議。
   請幫我快速準備：

   1. 摘要上一次 NPI Kick-off 會議的重點決議和行動項目
      （搜尋 Teams 頻道 #NPI-ProServerX200 或我最近的會議紀錄）

   2. 檢查上次會議的行動項目，哪些已完成？哪些逾期？
      （參考 /英業達_NPI_ProServerX200_專案追蹤.xlsx 的里程碑表）

   3. 本次會議的建議議程（根據上次未完成的項目和新的進展）

   4. 每位與會者最近在 Teams 頻道中的發言重點
      （Kevin Liu, Lisa Wang, Amy Hsu, Tom Lin, Sarah Chang）

   用條列格式，幫我在 10 分鐘內掌握全貌。
   ```
3. 展示 Copilot 的回應——它會從 Teams、郵件、Excel 中彙整資訊
4. 說明 Copilot 的跨 App 搜尋能力如何節省會前準備時間

> 💡 **教學 Tip**：很多人只在會後用 Copilot，但**會前準備**才是最被忽略的高價值場景。一個準備充分的主席 = 一場高效的會議。

### 步驟 2：用 Copilot 產生會議議程和引導語（5 分鐘）

1. 在 Copilot Chat 中繼續輸入：
   ```
   根據剛才的彙整，請產生今天會議的正式議程，格式如下：

   ProServer X200 設計審查會議 — 議程
   日期：2025/4/15 14:00-15:30
   主席：James Chen

   議程項目 | 負責報告人 | 預估時間 | 目標
   ---------|-----------|---------|-----
   1. 上次行動追蹤 | Sarah Chang | 5 min | 確認完成狀態
   2. 散熱方案審查 | Kevin Liu | 20 min | 審核液冷方案可行性
   3. 供應商評估結果 | Lisa Wang | 15 min | 確認 GPU/液冷供應商
   4. 品質測試規劃 | Amy Hsu | 15 min | DVT 計畫審查
   5. IT 系統更新 | Tom Lin | 10 min | ERP 建檔進度
   6. 風險回顧 | James Chen | 10 min | 風險登記簿更新
   7. 行動項目與下次會議 | James Chen | 5 min | 確認待辦

   同時，為每個議程項目準備 1-2 個我（主席）應該問的關鍵問題。
   ```
2. 展示產出的議程和引導問題
3. 這份議程可以直接貼到 Teams 會議邀請中

### 步驟 3：用 Copilot 預覽每位與會者的準備狀態（3 分鐘）

1. 輸入：
   ```
   根據 Teams 頻道和郵件，快速告訴我每位與會者的「準備狀態」：

   - Kevin Liu：散熱方案的熱模擬結果出來了嗎？
   - Lisa Wang：GPU 供應商評估報告完成了嗎？
   - Amy Hsu：DVT 測試計畫進度如何？
   - Tom Lin：ERP 建檔做到哪裡了？

   如果有人還沒回報，提醒我在會議開始前 30 分鐘追一下。
   ```
2. 展示 Copilot 從各資料來源彙整的與會者狀態
3. 說明這讓主席在會前就知道「今天會議可能卡在哪裡」

> 💡 **教學 Tip**：好的會議主席不是在會議中才發現問題，而是在會前就預判可能的瓶頸。Copilot 幫你做這個「預判」。

### 步驟 4：在 Teams 會議邀請中更新議程（2 分鐘）

1. 開啟 Teams 行事曆中的會議邀請
2. 將 Copilot 產生的議程貼入會議描述
3. 加入附件：**英業達_NPI_ProServerX200_專案追蹤.xlsx**
4. 發送更新通知

> 🎯 **會前 Takeaway**：
> - 會前用 Copilot 搜尋前次會議決議、行動追蹤、頻道最新動態
> - 自動產生議程 + 主席引導問題
> - 預判每位與會者的準備狀態，提前追蹤

# 第二段：會中協作（15 分鐘）

## Demo B：Facilitator 即時主持 + Copilot 私下輔助

> **情境**：會議開始了。James 同時使用兩個 AI 工具——Facilitator（公開）和 Copilot in Teams（私密）。

### 教學重點先說明：雙 AI 並用策略（2 分鐘）

| | Facilitator | Copilot in Teams |
|---|---|---|
| 誰看得到 | 👁️ 所有與會者 | 🔒 只有你自己 |
| 用途 | 公開的會議管理 | 私人的資料查詢 |
| 範例 | 「@Facilitator 記錄這個決議」 | 「Lisa 剛說的那個供應商報價數字對嗎？」 |
| 互動方式 | 在會議聊天中 @Facilitator | 在 Copilot 側邊面板 |

```
🎯 黃金組合：
Facilitator 管「面子」（公開管理、全員可見）
Copilot 管「裡子」（私下查資料、驗證數字）
```

### 步驟 1：啟用 Facilitator + 設定議程（3 分鐘）

1. 加入 Teams 會議
2. 開啟 **Notes** 面板（上方工具列）
3. 在會議聊天中輸入：
   ```
   @Facilitator 今天的設計審查會議議程如下，請追蹤進度：
   1. 上次行動追蹤 (5 min)
   2. 散熱方案審查 (20 min)
   3. 供應商評估結果 (15 min)
   4. 品質測試規劃 (15 min)
   5. IT 系統更新 (10 min)
   6. 風險回顧 (10 min)
   7. 行動項目 (5 min)
   
   會議總長 80 分鐘，請在 40 分鐘時提醒我們已到半程。
   ```
4. Facilitator 回應確認議程，並開始追蹤
5. 展示 **Visual Timeline Markers**——全員都能看到目前討論進度

### 步驟 2：會議進行中——Facilitator 的五大用法（5 分鐘）

展示以下五個用法，每個花 1 分鐘：

**用法 1：記錄重要決議**
```
@Facilitator 決議：散熱方案確認採用直接接觸液冷板 + CDU 架構，
GPU junction temp 目標 <85°C，實測 72°C 通過。
```
→ Facilitator 在 Notes 中記錄此決議，全員可見

**用法 2：標記行動項目**
```
@Facilitator 行動項目：Lisa Wang 在 4/25 前完成 CoolTech 供應商導入流程
```
→ Facilitator 記錄並在會議結束時彙整所有行動項目

**用法 3：即時議題追加**
```
@Facilitator 有人提出新議題：是否需要評估第二家液冷供應商？
請加入議程。
```
→ Facilitator 動態更新議程

**用法 4：半程提醒**
→ 在 40 分鐘時，Facilitator 自動提醒：「會議已到半程，還有 3 個議程項目未討論。」

**用法 5：請 Facilitator 摘要目前為止的討論**
```
@Facilitator 摘要目前為止的討論重點和已做的決議
```
→ 全員都能看到即時摘要，確保大家在同一頁

### 步驟 3：會議進行中——Copilot 的私密輔助（3 分鐘）

同時在 Copilot 側邊面板（只有你看到）做以下操作：

**私密用法 1：即時驗證數字**
```
Lisa 剛說 NovaTech 的報價是 $262-265，這跟之前郵件中 David Park 報的 $285 差很多。
請搜尋最近與 NovaTech 的郵件，確認最新的報價條件。
```
→ Copilot 搜尋郵件，幫你私下驗證

**私密用法 2：追問你不懂的技術名詞**
```
Kevin 剛提到「Cold Plate 的 thermal conductivity 需要 >6.0 W/mK」。
請簡單解釋 thermal conductivity 是什麼？6.0 W/mK 算高還是低？
```
→ Copilot 私下給你科普，不用在會議中承認你不懂

**私密用法 3：查看某人之前說過什麼**
```
Amy 之前在 Kick-off 會議中說 DVT 測試需要多少週？
她現在說的時程有沒有變？
```
→ Copilot 從上次會議的轉錄稿中搜尋

### 步驟 4：Wrap-up 提醒（2 分鐘）

1. 在會議結束前 5 分鐘：
   ```
   @Facilitator 請整理今天所有的行動項目，列出負責人和截止日期
   ```
2. Facilitator 在聊天中公布完整的行動清單
3. 所有人確認無誤
4. Facilitator 的 wrap-up reminder 自動提醒會議即將結束

> 🎯 **會中 Takeaway**：
> - Facilitator = 公開的 AI 主持人（全員看到）
> - Copilot in Teams = 私密的 AI 助理（只有你看到）
> - 雙 AI 並用：Facilitator 管會議流程，Copilot 幫你私下查資料
> - 決議、行動項目即時記錄，不用等會後整理

# 第三段：會後產出（20-25 分鐘）

## Demo C：多角度會議摘要——同一場會議，不同人需要不同的重點

> **情境**：設計審查會議結束了。但「會議紀錄」不是只有一份——不同的人需要不同的版本：
> - **CEO/VP** 需要：一段話的結論 + 需要決策的事項
> - **PM** 需要：完整行動清單 + 風險追蹤
> - **一般工程師** 需要：跟我有關的部分 + 我要做什麼
> - **客戶（HP）** 需要：可以對外分享的進度更新（不含內部數據）

### 步驟 1：使用 Teams 內建 AI Summary（3 分鐘）

1. 會議結束後，在 Teams 行事曆中找到剛結束的會議
2. 點擊進入 **Recap** 頁面
3. 展示自動產生的內容：
   - 📝 **Summary**：會議摘要
   - 🎯 **Action Items**：行動項目
   - 📌 **Mentions**：被提到的人名
   - 🕐 **Topics by Timeline**：依時間軸的主題標記
4. 說明這是 Copilot 的「標準版」摘要——一般用途

### 步驟 2：產生 CEO/VP 角度的摘要（5 分鐘）

1. 在 Copilot 側邊面板中輸入：
   ```
   請用「製造副總 Robert Tsai」的角度重新摘要這場會議。
   他只有 30 秒讀這份摘要。

   格式：
   🚦 整體狀態：🟢🟡🔴（一個燈號）
   📌 一句話結論：（20 字以內）
   ⚡ 需要您決策的事項：（最多 2 項，每項一句話）
   💰 成本影響：（如果有的話，一個數字）
   ⏰ 下一個關鍵里程碑：（日期 + 內容）

   不要細節，不要技術術語，只要結論和行動。
   ```
2. 展示 Copilot 產出的 CEO 版摘要
3. 強調：**同一場會議的資訊，對高階主管和一般員工的呈現方式完全不同**

**範例產出**：
```
🚦 整體狀態：🟡 黃燈
📌 一句話結論：散熱方案確認可行，但液冷供應商需盡快導入
⚡ 需要您決策：
  1. 核可 SiliconEdge 備援供應商驗證費用 USD 45,000
  2. 核可選用 CoolTech（台灣）而非 ThermalPro（中國）作為液冷模組供應商
💰 成本影響：CoolTech 年化成本較 ThermalPro 高 USD 1.38M，但品質風險顯著降低
⏰ 下一個里程碑：4/30 DVT 測試計畫完成
```

### 步驟 3：產生 PM 角度的完整行動追蹤版（3 分鐘）

1. 繼續在 Copilot 中輸入：
   ```
   請用「專案經理」的角度摘要這場會議。我需要追蹤每一個細節。

   格式：
   一、決議事項（每項含：決議內容 / 決議原因 / 影響範圍）
   二、行動項目表格：
       編號 | 負責人 | 行動項目 | 截止日 | 相依項目 | 風險等級
   三、風險更新（新增/升級/已緩解的風險）
   四、時程影響評估（是否影響量產日期？）
   五、下次會議議程預覽
   ```
2. 展示完整的 PM 版——比 CEO 版詳細 10 倍

### 步驟 4：產生一般員工角度的個人化摘要（3 分鐘）

1. 輸入：
   ```
   請用「QA 工程師 Amy Hsu」的角度摘要這場會議。
   只保留跟 Amy 有關的部分。

   格式：
   📋 跟我有關的決議：
   ✅ 我需要做的事：（行動項目 + 截止日）
   📎 我需要的資源/input：（誰要給我什麼、什麼時候）
   ⚠️ 需要注意的風險：
   📅 重要日期：
   ```
2. 展示個人化摘要

3. 再示範另一個角度——IT Tom Lin：
   ```
   同樣的格式，改用「IT 系統工程師 Tom Lin」的角度。
   只保留跟 IT 有關的事項。
   ```
4. 展示差異——同一場會議，Amy 看到的是測試計畫，Tom 看到的是 ERP 建檔

> 💡 **教學 Tip**：這就是 Copilot 最強大的地方——**同一份資料，不同的 prompt 產出不同角度的解讀**。這比手動寫 4 份不同版本的會議紀錄快 10 倍。

### 步驟 5：產生客戶報告角度的摘要（3 分鐘）

1. 輸入：
   ```
   請產生一份可以分享給客戶 HP Enterprise 的會議進度更新。

   注意以下原則：
   ❌ 不可包含：內部成本數字、供應商報價、BOM 細節、內部爭論
   ✅ 可以包含：設計進度、測試計畫、里程碑達成狀態、下一步

   格式：
   ProServer X200 — Development Progress Update
   Date: April 15, 2025
   
   Summary: [1 段英文摘要]
   Key Milestones: [已達成 + 即將到來的]
   Design Status: [簡要技術進展，不含供應商名稱]
   Test Planning: [DVT 計畫概述]
   Next Steps: [接下來的動作]
   
   語氣：專業自信，展現進度順利。英文撰寫。
   ```
2. 展示客戶版——注意它自動過濾掉了內部敏感資訊

> ⚠️ **教學 Tip（重要！）**：永遠要人工檢查客戶版是否洩漏了內部資訊。Copilot 通常做得不錯，但如果 prompt 中有供應商名稱、報價等，它可能會不小心帶入。**這是負責任的 AI 使用——AI 產出後要人工審核。**

### 步驟 6：用 Word 產出正式會議紀錄（5 分鐘）

1. 開啟 Word，新文件
2. 使用 Copilot Draft with Copilot，輸入：
   ```
   請根據 /英業達_NPI_設計審查會議逐字稿.docx 的會議內容，
   產出一份正式的會議紀錄文件，格式如下：

   ═══════════════════════════════════════
   英業達股份有限公司
   會議紀錄 (Meeting Minutes)
   ═══════════════════════════════════════

   會議名稱：ProServer X200 設計審查會議
   日期/時間：2025/4/15 14:00-15:30
   地點：桃園總部 3F 會議室 B / Teams
   主席：James Chen
   紀錄：[AI Generated]
   出席者：[從逐字稿中提取]

   一、上次行動追蹤（表格：行動項目 / 負責人 / 狀態）
   二、本次討論重點（按議程分段摘要）
   三、決議事項（編號清單）
   四、新增行動項目（表格：編號 / 負責人 / 項目 / 截止日）
   五、風險更新
   六、下次會議資訊

   語氣正式。中文。
   ```
3. 展示 Copilot 產出的正式會議紀錄
4. 使用 Rewrite 微調個別段落

5. 進階操作——加入「出席者簽名欄」：
   ```
   請在文件最後加入出席者確認簽名欄：
   
   本紀錄由 AI 輔助產生，經以下人員確認無誤：
   
   姓名          | 部門    | 確認簽名  | 日期
   James Chen    | PM      |           |
   Kevin Liu     | R&D     |           |
   Lisa Wang     | SCM     |           |
   Amy Hsu       | QA      |           |
   Tom Lin       | IT      |           |
   Sarah Chang   | BPM     |           |
   ```

### 步驟 7：客製化會議紀錄——不同格式的產出（3 分鐘）

展示同一份逐字稿可以產出不同格式的文件：

**格式 A — 傳統正式會議紀錄**（上面已做）

**格式 B — 一頁式摘要（One-Pager）**
```
請把剛才的會議紀錄濃縮成一頁 A4 的摘要，只保留：
- 3 個最重要的決議
- 5 個關鍵行動項目
- 2 個最高風險

**格式 C — Email Friendly 版本**
```

> - 客戶版要特別注意審核是否洩漏內部資訊

## 綜合對比表：四種角度的會議摘要

| 維度 | CEO/VP 版 | PM 版 | 個人版 | 客戶版 |
|------|----------|-------|--------|--------|
| **長度** | 5 行 | 2 頁 | 半頁 | 1 頁 |
| **決議** | 只列需要決策的 | 全部列出 + 原因 | 只跟我有關的 | 過濾內部的 |
| **行動項目** | 不列（或只列需要核准的） | 完整表格 | 只有「我」的 | 不列內部分工 |
| **數字** | 只有金額影響 | 完整數據 | 不需要 | 不含成本/報價 |
| **風險** | 只有最高風險 | 完整風險登記簿 | 影響我的風險 | 不提內部風險 |
| **語氣** | 極簡、結論導向 | 詳細、追蹤導向 | 親切、任務導向 | 專業、正面 |
| **語言** | 中/英皆可 | 中文為主 | 中文 | 英文 |
